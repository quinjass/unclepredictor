Política de Privacidade — Uncle Predictor

Última atualização: 17 de junho de 2026

A presente política descreve como a aplicação e o site Uncle Predictor (“a aplicação”) recolhem, utilizam e protegem os dados dos utilizadores. A aplicação é um jogo social de previsões de resultados de futebol, sem fins lucrativos.

1. Responsável pelo tratamento

Uncle Predictor (projeto pessoal). Contacto: unclepredictor@gmail.com.

2. Que dados recolhemos

Recolhemos apenas o necessário ao funcionamento do jogo:

  • Dados de conta: nome, endereço de email e um código de jogador.
  • Atividade de jogo: as tuas previsões/apostas, pré-apostas, ligas a que pertences, comentários e reações.
  • Notificações: um identificador técnico do dispositivo (token de notificações) para te enviarmos avisos do jogo (prazos, resultados, menções).
  • Dados técnicos mínimos: informação guardada localmente no teu dispositivo (sessão) para te manter com sessão iniciada.

A aplicação não recolhe localização, contactos, fotografias, nem dados de pagamento.

3. Para que usamos os dados

Os dados são usados exclusivamente para: autenticar a tua conta, registar e pontuar as tuas previsões, gerir as ligas e a componente social, e enviar notificações relacionadas com o jogo. Não usamos os dados para publicidade.

4. Onde guardamos os dados

Os dados são guardados em serviços da Google: Google Sheets e Google Apps Script (base de dados e servidor do jogo) e Firebase Cloud Messaging (envio de notificações). O acesso é restrito ao responsável pelo projeto.

5. Partilha com terceiros

Não vendemos nem partilhamos os teus dados com terceiros para fins comerciais. Os dados apenas transitam pelos serviços técnicos referidos no ponto 4, necessários ao funcionamento da aplicação.

6. Conservação e eliminação

Os dados são conservados enquanto a tua conta estiver ativa. Podes pedir a eliminação da tua conta e de todos os dados associados a qualquer momento, contactando o email acima. O pedido será atendido num prazo razoável.

7. Os teus direitos

Tens o direito de aceder, corrigir ou eliminar os teus dados pessoais. Para exercer estes direitos, contacta unclepredictor@gmail.com.

8. Menores

A aplicação destina-se a um público geral e não se dirige especificamente a crianças. Não recolhemos intencionalmente dados de menores de 13 anos.

9. Alterações a esta política

Podemos atualizar esta política. A data da última atualização é indicada no topo desta página.

10. Contacto

Para qualquer questão sobre privacidade: unclepredictor@gmail.com.
