========================================
  UNCLE PREDICTOR 2026 — COMO CONFIGURAR
========================================

FICHEIROS INCLUÍDOS:
  index.html      → A aplicação web (envia para Netlify)
  apps-script.gs  → O backend (cola no Google Apps Script)
  INSTRUCOES.txt  → Este ficheiro

O processo tem 3 passos: Google Sheet → Apps Script → Netlify
Demora cerca de 20 minutos.

----------------------------------------
PASSO 1 — CRIAR O GOOGLE SHEET
----------------------------------------
1. Vai a https://sheets.google.com
2. Cria uma nova folha de cálculo
3. Dá-lhe o nome "Uncle Predictor 2026"
4. Copia o ID da URL:
   https://docs.google.com/spreadsheets/d/  [ESTE_ID_AQUI]  /edit
5. Guarda este ID — vais precisar dele no passo 2.

----------------------------------------
PASSO 2 — CONFIGURAR O APPS SCRIPT
----------------------------------------
1. No Google Sheet, vai a: Extensões → Apps Script
2. Apaga o código que lá está
3. Cola TODO o conteúdo do ficheiro "apps-script.gs"
4. Substitui:
     const SHEET_ID = 'COLE_AQUI_O_ID_DO_GOOGLE_SHEET';
   pelo ID que copiaste no passo 1. Ex:
     const SHEET_ID = '1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgVE2upms';

5. Muda a password de admin (opcional mas recomendado):
     const ADMIN_PASSWORD_DEFAULT = 'admin2026';
   Substitui 'admin2026' pela password que quiseres.

6. Clica em "Guardar" (ícone de disquete)

7. Faz o deploy:
   a. Clica em "Implementar" → "Nova implementação"
   b. Tipo: "Aplicação Web"
   c. Executar como: "Eu (o teu email)"
   d. Quem tem acesso: "Qualquer pessoa"
   e. Clica "Implementar"
   f. Autoriza o acesso quando pedido
   g. Copia o URL que aparece (ex: https://script.google.com/macros/s/XXXX/exec)
   GUARDA ESTE URL — é o backend da tua app!

----------------------------------------
PASSO 3 — CONFIGURAR O FICHEIRO HTML
----------------------------------------
1. Abre o ficheiro "index.html" com o Notepad (ou qualquer editor de texto)
2. Procura esta linha (está no início do JavaScript):
     const SCRIPT_URL = 'COLE_AQUI_O_URL_DO_APPS_SCRIPT';
3. Substitui pelo URL do passo 2g. Ex:
     const SCRIPT_URL = 'https://script.google.com/macros/s/ABC123/exec';
4. Guarda o ficheiro.

----------------------------------------
PASSO 4 — PUBLICAR NO NETLIFY (GRATUITO)
----------------------------------------
1. Vai a https://www.netlify.com e cria conta gratuita (ou entra com Google)
2. No painel, arrasta a PASTA que contém o index.html para a área indicada
   (ou clica "Browse to upload" e seleciona a pasta)
3. O Netlify publica em segundos e dá-te um link do tipo:
     https://amazing-name-12345.netlify.app
4. Podes personalizar o nome em: Site configuration → Site details → Change site name
   Ex: https://uncle-predictor-2026.netlify.app

----------------------------------------
PASSO 5 — ADICIONAR PARTICIPANTES
----------------------------------------
1. Abre o link da tua app no browser
2. Faz login com qualquer nome + a password de admin (ex: admin2026)
3. Vai ao separador "Admin" → "Participantes"
4. Adiciona cada amigo com:
   - Nome: Hugo
   - Código: HUGO2026 (podes inventar — é este que envias a cada pessoa)
5. Envia o link e o código a cada participante

----------------------------------------
UTILIZAÇÃO DIA-A-DIA
----------------------------------------
PARTICIPANTES:
- Abrem o link no telemóvel/pc
- Entram com o seu nome e código
- "Apostas": preenchem resultados + escolhem JOKER antes de cada jornada
- "Pré-Apostas": preenchem grupos e apostas especiais (antes de 11 Jun)
- "Classificação": veem o leaderboard atualizado

ADMINISTRADOR (tu):
- Vais ao separador "Admin"
- Entras com a password de admin
- Após cada jogo: introduzes o resultado em "Resultados" e clicas "Guardar"
- O sistema calcula e atualiza a classificação automaticamente

----------------------------------------
SISTEMA DE PONTUAÇÃO (RESUMO)
----------------------------------------
Fase de Grupos (por jogo):
  - Resultado exato:              3 pontos
  - Resultado exato + JOKER:      5 pontos
  - Acertou vencedor (não score): 1 ponto
  - Errou tudo:                   0 pontos

JOKER: 1 por jornada (3 jornadas = 3 JOKERs na fase de grupos)

Pré-Apostas (antes do torneio):
  - 1º ou 2º de cada grupo:      2 pontos cada (24 grupos x2 = máx. 48pts)
  - Campeão do mundo:             8 pontos
  - Vice-campeão:                 5 pontos
  - 3º classificado:              3 pontos
  - Melhor marcador:              5 pontos

Critérios de desempate (por ordem):
  1. Número de vitórias (resultado exato)
  2. Número de empates (vencedor certo)

----------------------------------------
MODO DEMO
----------------------------------------
Enquanto o SCRIPT_URL não estiver configurado, a app funciona em
"modo demo": tudo funciona visualmente mas os dados não são partilhados
entre utilizadores nem guardados no servidor.
É útil para testar antes de configurar o backend.

----------------------------------------
SUPORTE / DÚVIDAS
----------------------------------------
Se algo não funcionar, verifica:
1. O SHEET_ID está correto no apps-script.gs
2. O SCRIPT_URL está correto no index.html (sem espaços extra)
3. O Apps Script foi deployado como "Qualquer pessoa pode aceder"
4. Voltaste a fazer deploy após alterar o código do Apps Script

Boa sorte e bom Mundial! 🏆
